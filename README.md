# Hamoula

Application web qui met en relation les transporteurs de marchandises et les expéditeurs en Algérie, avec une priorité : trouver un chargement pour le trajet retour.

- Connexion : compte Google (Firebase Authentication)
- Données : Cloud Firestore (projet `hamoula-780a1`)
- Règles de sécurité : `firestore.rules` (à coller dans Firestore › Règles)
- Hébergement : GitHub Pages

Version de test gratuite.
